# Changelog

All notable changes for major milestone releases.

## [v0.4.14] - 2026-03-05
- Marked the current build as a stable release checkpoint.
- Updated versioned documentation and release metadata for tagging.

## [v0.4.13] - 2026-02-27
- Added a substantial desktop movement update with always-on mouse look and responsive jetpack controls.
- Introduced a momentum-based jetpack vertical arc: short lift, controlled drift, and natural descent.
- Improved jetpack input handling so launches can happen while moving and on varied terrain.
- Prevented an immediate relaunch when landing with Space held, requiring a fresh Space press to re-engage jet lift.

## [v0.4.0] - 2025-12-05
- Initial release: terrain, seeded world generation, resource gathering loop, and HUD/status UI.
